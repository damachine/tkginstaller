## TKG-Installer - Logs

---

**Browse build and system logs created by TKG-Installer for each package.**

---

### Available Logs

- **Linux-TkG:** `~/.tkginstaller/.cache/linux-tkg/logs/`
- **Nvidia-all:** `~/.tkginstaller/.cache/nvidia-all/logs/`
- **Wine-TkG:** `~/.tkginstaller/.cache/wine-tkg-git/logs/`
- **Proton-TkG:** `~/.tkginstaller/.cache/wine-tkg-git/logs/`

---

### How to Use

1. Select `Logs` from the main menu.
2. Choose a package with available log files.
3. Select a file to preview it or open it in the pager.

---

### Tips

- Use logs when a build or installation fails.
- `Ctrl+P` toggles the preview window.
- `ESC` returns to the previous menu.
